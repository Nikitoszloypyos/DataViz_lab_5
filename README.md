# Лабораторная работа № 5

Два интерактивных дашборда по данным из лабораторной работы № 4:

- Plotly Dash;
- Streamlit.

Основной датасет — `FiresRu.csv`, содержащий 26 681 наблюдение о пожарах с координатами и метеорологическими характеристиками.

## Что показывают дашборды

- количество отфильтрованных наблюдений;
- долю лесных пожаров;
- медианную температуру;
- долю наблюдений с осадками не более 0,1 мм;
- распределение типов пожаров;
- распределение температуры;
- скорость ветра по типам пожаров;
- географическую плотность наблюдений;
- таблицу отфильтрованных записей.

Фильтры позволяют выбирать типы пожаров, диапазон температуры и диапазон осадков.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

В Windows команда активации окружения:

```powershell
.venv\Scripts\activate
```

## Запуск Plotly Dash

```bash
python app.py
```

После запуска открыть: http://127.0.0.1:8050

## Запуск Streamlit

```bash
streamlit run streamlit_app.py
```

После запуска открыть адрес, указанный в терминале. Обычно это http://localhost:8501.

## Структура проекта

- `app.py` — приложение Plotly Dash;
- `streamlit_app.py` — приложение Streamlit;
- `dashboard_data.py` — общая загрузка данных, фильтрация, показатели и графики;
- `FiresRu.csv` — данные;
- `requirements.txt` — зависимости проекта.

Оба приложения используют единый модуль расчётов, поэтому одинаковые фильтры дают одинаковые показатели.

## Источник данных

[Метеорологические условия пожаров на территории России (2021–2022)](https://data.rcsi.science/data-catalog/datasets/209/), каталог ИНИД.
